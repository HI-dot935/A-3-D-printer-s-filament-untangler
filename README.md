# A-3-D-printer-s-filament-untangler

# WHat's the project all about? 

So basically this is a 3-D printer's filament untangler. As many of those who have 3d printer suffer this problem of getting prints failed due to the filament getting tangled causing them loss of filament, time &amp;  electricity bills. So to avoid this a small simple solution an untangler for the filament.
